# Changelog

## 1.0.0
- First release: core (registry, shared math, `apply`, `options`, `enable`) and nine indicators: SMA, EMA, Bollinger Bands, VWAP, RSI, MACD, Stochastic, ATR, OBV.
- Overlay indicators work in Chart and StockChart; pane indicators work in StockChart and are ignored with a console warning in a plain Chart.
- Panes inherit axis, tooltip and legend styling from the price chart.
